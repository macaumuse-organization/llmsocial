# 接真号清单

按难度排好了：**从上往下做，前两个不需要公网地址**。每一步都写了去哪拿、填在 llmsocial 哪里、填完看什么算成功。

平台要求和坑的细节在 [平台接入](平台接入.md)，这里只管「照着做」。

---

## 零、先做一次（所有平台共用）

### 1. 升级 Node

要 Node.js 22.18 或更新，推荐 24 LTS。装完在仓库目录跑：

```bash
npm run check
```

全绿再往下。

### 2. 建 `.env`

把 `.env.example` 复制成 `.env`。现在什么都不用改，默认值能直接跑；等到做回调类平台（第三步以后）再回来填 `LLMSOCIAL_PUBLIC_WEBHOOK_URL`。

**`.env` 只管服务器本身，平台密钥不写在这里**——除非你想用下面第 4 条的做法。

### 2.5 这台电脑要开 VPN 才能上 Google？打开代理开关

**浏览器能打开 Google，不代表程序能连上**：浏览器自动走 Windows 系统代理，Node 程序不走。症状是授权最后一步显示「连不上 oauth2.googleapis.com」。

1. Windows「设置 → 网络和 Internet → 代理」，看手动代理那里的地址和端口（比如 `127.0.0.1:18081`）
2. llmsocial「设置」页 →「网络代理」卡片：勾上「对外请求走代理」，代理地址填 `http://127.0.0.1:端口`，点右上角「保存」。**立刻生效，不用重启**
3. 点「测试网络」：「Google（YouTube 授权用）」那行显示 ✓ 就通了

「不走代理的地址」默认已经填好本机和国内服务：VPN 关掉时千问、微信照样能用，只有海外平台会断。不开 VPN 的日子，把开关关掉、保存就行。

以前在 `.env` 里写过 `HTTPS_PROXY` 的：第一次用新版启动时会自动搬进这张卡片并打开开关，之后以设置页为准。

### 3. 配一个真模型

「模型」页 → 新增 → 选 Anthropic，填 API key。默认模型是 `claude-opus-5`。点「测试连接」通过就行。

不配的话系统只有离线 Mock，能跑流程但回复是假的。

### 4. 密钥填法（二选一）

| 做法 | 怎么填 | 适合 |
|---|---|---|
| 直接填 | 界面里把密钥原样贴进去，加密后存进数据库 | 省事 |
| 引用环境变量 | `.env` 里写 `X_CLIENT_SECRET=真实的值`，界面那一栏填 `env:X_CLIENT_SECRET` | 不想让密钥进数据库和备份 |

两种可以混用。下面每个平台都用「界面里的字段名」来说，哪种填法都行。

## 一、YouTube（评论区）——不需要公网地址

**能做什么**：收你频道视频下的评论，AI 起草回复。YouTube 没有私信。另外能收「谁公开订阅了你」作为线索。

**状态**：2026-09-24 用真号跑通——视频和 Shorts 下的评论都收到了，批准后的回复出现在 YouTube 上。订阅线索还没用真号跑过。

**去哪准备**：

1. [Google Cloud 控制台](https://console.cloud.google.com/) 建一个项目
2. 「API 和服务 → 库」里启用 **YouTube Data API v3**
3. 「Google Auth Platform」（https://console.cloud.google.com/auth/overview ）点「开始」：应用名称、用户支持邮箱、开发者联系邮箱（打完要按回车变成小方块才算填上），目标对象选「外部」。**不要上传徽标**——一上传就必须提交 Google 验证。然后二选一：
   - **简单（推荐先用这个）**：保持「测试」状态，在「受众群体 → 测试用户」里加上管理这个频道的 Google 邮箱。代价是授权**每 7 天失效一次**（Google 官方规定，只跟「测试」状态有关）：到期后账号卡片会显示「待授权」，点「去授权」重新登录一次就好
   - **省心**：发布成「正式版」，授权长期有效，也不用提交 Google 审核。但 Google 要求先在「品牌」页填**应用首页**和**隐私权政策链接**——必须是你自己域名下能打开的真实页面——并把这个域名加进「已获授权的网域」，否则「发布应用」按钮是灰的
4. 「凭据 → 创建凭据 → OAuth 客户端 ID」，类型选 **Web 应用**，「已获授权的重定向 URI」填：

   ```
   http://127.0.0.1:8787/oauth/callback
   ```

   一个字都不能差，包括末尾没有斜杠。

**在 llmsocial 里填**：「账号」→ 新增 → 平台选 YouTube，连接方式选「YouTube」

| 界面字段 | 填什么 |
|---|---|
| OAuth 客户端 ID | 上面第 4 步拿到的客户端 ID |
| OAuth 客户端密钥 | 同一处的客户端密钥 |

保存后在账号卡片上点「**去授权**」，用拥有这个频道的 Google 账号登录并同意。

想收订阅线索：编辑账号，「线索收集间隔（秒）」填 `3600`。

**怎么算跑通**：

1. 账号卡片点「测试连接」，显示你的频道名和公开视频数；再点「立即拉取」，不报错
2. 用另一个号在你**视频**下留一条评论（Shorts 也行），等一两分钟，收件箱里出现
   - 社区「帖子」下的评论收不到：YouTube 没有把帖子开放给程序，频道里至少要有一个公开视频
   - 频道主人自己发的评论不会被回复，所以一定要换个号
   - 等了还不出现：YouTube 工作室 →「评论」，看是不是被放进了「待审核」，批准后再点「立即拉取」
3. 起草、批准，回到 YouTube 看评论区有没有你的回复
4. 账号卡片上「上次收到」和「上次发出」都有时间了，标签从「还没跑通收发」变成「收发已跑通」

**配额**：每天 10000 单位免费。拉评论 1 单位一次，**回一条评论 50 单位**，所以一天大约能回 200 条。

## 二、X（提及与私信）——不需要公网地址

**X 的接口按条收费**：没有免费额度，旧的 Basic / Pro 月费套餐不再对新开发者开放。提及和私信都能用（[官方价目表](https://docs.x.com/x-api/getting-started/pricing)，2026-09-24 查）：

| 动作 | 价格 |
|---|---|
| 读一条帖子（收 @提及） | $0.005 |
| 读一条私信 | $0.01 |
| 发一条回复 / 私信 | $0.015（帖子里带链接 $0.20） |

同一条内容一天（UTC）内重复读只算一次。先在开发者后台充值、**设好花费上限**再接。私信要是被拒（应用权限没开私信、额度用完），系统会在账号卡片上写明原因，提及照常收，不会假装「没人私信」。

**去哪准备**：

1. [developer.x.com](https://developer.x.com/) → 建 Project 和 App
2. App 设置里开启 **OAuth 2.0**，类型选 Web App / Automated App or Bot
3. 权限选 **Read and write and Direct message**
4. Callback URI 填：

   ```
   http://127.0.0.1:8787/oauth/callback
   ```

**在 llmsocial 里填**：「账号」→ 新增 → 平台选 X，连接方式选「X（Twitter）」

| 界面字段 | 填什么 |
|---|---|
| Client ID | App 的 OAuth 2.0 Client ID（必填） |
| Client Secret | 同一处的 Client Secret（公开客户端可以留空） |

保存后点「去授权」。

**怎么算跑通**：用另一个号 @你一条，收件箱出现 → 起草批准 → X 上看到回复。

## 三、准备公网地址（公众号、企业微信必须；Instagram 可选）

微信公众号、企业微信客服只会**平台主动推消息给你**，所以需要一个外网能访问的 HTTPS 地址指向你电脑的 **8788 端口**。Instagram 也能推，但不配的话 llmsocial 每 2 分钟自己去拉一次，一样能用。

**推荐 Cloudflare Tunnel**：免费、固定域名、自带 HTTPS。只暴露 8788，**千万别暴露 8787**——那是管理界面。

装好隧道之后：

1. 把隧道域名填进 `.env`：

   ```
   LLMSOCIAL_PUBLIC_WEBHOOK_URL=https://你的隧道域名
   ```

2. 重启 llmsocial
3. 每个账号卡片上会显示它自己的回调地址（`https://你的隧道域名/webhooks/账号ID`），右边有复制按钮——**填到平台后台用的就是这个**

**怎么判断隧道通了**：在平台后台保存回调地址时，平台会发一次验证请求。账号卡片上「**上次回调**」从「从没收到」变成一个时间，就说明平台打得进来、签名也对上了。

## 四、Instagram（私信和评论）——不需要公网地址（回调可选）

**前提**：

- 你的 Instagram 必须是**专业号**（创作者或商家）。个人号可以在 App 里「设置 → 账号类型和工具 → 切换为专业账号」，免费，随时能切回
- Instagram App 里打开「**允许访问消息**」：「设置 → 消息和快拍回复 → 消息控制 → 已连接的工具」（各版本措辞略有不同）

**去哪准备**（只收发你自己或你管理的号，用 Standard Access 就够，**不用过 Meta 应用审核**；给别人的号用才要审核）：

1. [developers.facebook.com](https://developers.facebook.com/) →「My Apps → Create App」。界面让你选用例（use case）就选 **Manage messaging & content on Instagram**；老版界面让你选类型就选「Other → Business」，建好后在「Add a product」里给 Instagram 点「Set up」
2. 左侧 Instagram 下点「**API setup with Instagram login**」（不要选 Facebook login 那个）
3. 「App roles → Roles → Add People」，角色选 **Instagram Tester**，填你专业号的用户名。然后到 instagram.com 网页版接受邀请：「设置 → 网站权限 → 应用和网站 → 测试者邀请」（Settings → Website permissions → Apps and websites → Tester invites）→ 接受
4. 回到「API setup with Instagram login」→「Generate access tokens」→「Add account」，登录你的专业号并允许 → 点「Generate token」，**马上复制**，令牌只显示一次。它 60 天有效，llmsocial 每 7 天自动续期

Webhook 可选：想让消息秒到才需要，要先有公网 HTTPS 地址（见第三节），订阅 `messages` 和 `comments`。不配就每 2 分钟拉一次。

**在 llmsocial 里填**：「账号」→ 新增 → 平台选 Instagram，连接方式选「Instagram 私信与评论」

| 界面字段 | 填什么 |
|---|---|
| 访问令牌（长期） | 第 4 步的令牌（必填） |
| 应用密钥（App Secret） | 只有配 webhook 才要填：「App settings → Basic → App secret」 |
| 回调校验令牌（Verify Token） | 只有配 webhook 才要填，自己编一串，两边一致 |

保存后点「测试连接」，显示你的 Instagram 用户名就对了。

**怎么算跑通**：用另一个 Instagram 号给你的专业号发一条私信 → 点「立即拉取」或等 2 分钟 → 收件箱出现 → 批准 → 小号收到回复。

- 私信只能在对方最后一条消息后 24 小时内回复，所以一定要「对方先发」
- 小号的私信一直不出现：把小号也按第 3 步加成 Instagram Tester 再试（开发模式下 Meta 可能只放行在应用里有角色的账号，这点还没用真号确认）

## 五、微信公众号——需要公网地址

**前提**：必须是**已认证的服务号**。订阅号没有客服消息接口。

**去哪准备**（公众号后台 → 设置与开发 → 基本配置）：

1. 记下 AppID、AppSecret
2. 「**IP 白名单**」：加上你电脑的公网出口 IP——不加的话每个接口都返回 40164
3. 「服务器配置」：URL 填账号卡片上的回调地址；Token 自己编；EncodingAESKey 点随机生成；消息加解密方式选**安全模式**

**在 llmsocial 里填**：「账号」→ 新增 → 平台选微信，连接方式选「微信公众号」

| 界面字段 | 填什么 |
|---|---|
| AppID | 基本配置里的 AppID |
| AppSecret | 基本配置里的 AppSecret |
| Token（令牌） | 服务器配置里你编的那个 Token |
| EncodingAESKey | 服务器配置里的 EncodingAESKey |

**顺序很重要**：先在 llmsocial 里把账号建好、密钥填好，**再**去公众号后台点「提交」——提交时平台会立刻打一次验证请求，llmsocial 这边没准备好就会失败。

**怎么算跑通**：用你的微信给公众号发一句话 → 收件箱出现 → 起草批准 → 微信收到回复。客服消息只能在对方发消息后 48 小时内回。

## 六、企业微信客服——需要公网地址

**去哪准备**（企业微信管理后台）：

1. 「应用管理 → 微信客服」，拿到**企业 ID（CorpID）**和**客服 Secret**（注意是微信客服的 Secret，不是通讯录的）
2. 建一个客服帐号，记下它的 **open_kfid**
3. 「**企业可信 IP**」：加上你电脑的公网出口 IP——不加的话全部返回 60020
4. 回调配置：URL 填账号卡片上的回调地址，Token 和 EncodingAESKey 自己生成，**必须用安全模式**

**在 llmsocial 里填**：「账号」→ 新增 → 平台选微信，连接方式选「微信客服（企业微信）」

| 界面字段 | 填什么 |
|---|---|
| 企业 ID（CorpID） | 第 1 步 |
| 客服帐号 ID（open_kfid） | 第 2 步 |
| 客服 Secret | 第 1 步 |
| 回调 Token | 第 4 步 |
| 回调 EncodingAESKey | 第 4 步 |

一个 llmsocial 账号对应一个客服帐号。

**怎么算跑通**：用微信打开客服链接发一句话 → 收件箱出现 → 起草批准 → 微信收到。每次对方发消息后 48 小时内最多回 5 条。

## 七、微信个人号（聊天桥）——只在 Windows 上，不需要公网地址

**前提**：llmsocial 和微信 Windows 版跑在同一台电脑上（微信 4.1 或更新，Windows 11）。

**在 llmsocial 里填**：「账号」→ 新增 → 平台选微信，连接方式选「通用 Webhook」，名称随便，出站 URL 留空，共享密钥留空（自动生成）→ 保存 → 卡片上点「安装聊天桥」。第一次会下载约 100 MB，并弹一次管理员确认（点「是」）。看到「就绪」后把微信整个退出再打开一次。

**怎么算跑通**：微信里多选几条消息 → 转发 → 转发到其他应用 → 选择电脑中的应用 → 聊天桥 → 收件箱出现这个联系人的对话，AI 起草一条回复。回复自己复制到微信发。第一次转发一段有你自己回复的单聊时，聊天桥会问一次「哪个是你自己」（导出的记录里没写），选一下就记住了；群聊会问一次群名。

**没跑通看哪**：卡片上的聊天桥状态一行会写下一步；聊天桥自己的窗口（双击 `%LOCALAPPDATA%\Programs\WeChatBridge\WeChatBridge.exe`）里有每次转发的记录和失败原因。微信菜单里没有它：先整个退出微信再开；还没有就点「重新安装」。

## 首次接真号的做法

1. **先用小号**，任务模式设成「只起草（copilot）」
2. 观察几天：草稿质量、有没有该拦没拦的、平台有没有报错
3. 确认稳了再考虑「自动回复（autopilot）」

每个账号卡片上的「上次收到 / 上次发出 / 上次回调」就是你的体检表：哪一项一直是「还没有」，问题就在那一段。

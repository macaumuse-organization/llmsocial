# 课堂教学用法

整套东西可以在**不连网、不花钱、不碰任何真实账号**的情况下演示：内置的 Mock 模型是离线确定性的，沙盒账号不连任何平台。投屏前把「模型」页里 Mock 的优先级数字改小（数字越小越先用，改成 1 就行）。

真要看真模型的效果，配一个 key（建议用 `keychain:` 引用，别在课上把密钥打在屏幕上），在任务里指定模型优先级。

---

## 一节课的流程（90 分钟）

### 1. 先看一遍全貌（10 分钟）

「沙盒」页 → 选「默认：友好回复」→ 人设写「刷到短视频，对数字人好奇但有点怀疑」→ 最多 3 轮 → 开始。

右侧逐条出现对话。跑完出评分：目标达成、自然度、推销压迫感、诚实性违规。

**讲什么**：这不是一个聊天机器人，是一条流水线。收消息 → 判断要不要回 → 组装上下文 → 生成 → 检查 → 排期 → 发送。学生第一次看到的应该是这条链路，不是提示词。

### 2. 拆提示词（20 分钟）

「收件箱」→ 随便一个会话 → 右栏「模型调用」→ 点某一条的「提示词」。

能看到三段：静态系统提示（可缓存的规则前缀）、动态系统提示（这个账号的人设、这个任务的目标和事实、装载的技能）、用户消息（对话历史 + 联系人记忆）。

**讲什么**：
- 为什么要分静态/动态 → 缓存与成本。
- 技能是怎么被「装载」的：`campaign.skillIds` + 平台过滤，不是把所有技能都塞进去。
- 里面那个 `CANARY-xxxx` 是干什么的 → 检测模型有没有把系统提示复述出去。

### 3. 改一个技能再跑一次（20 分钟）

「技能」页 → 打开 `rapport-basics` → 改几句 → 回沙盒用同样的人设再跑一次 → 对比两次的评分和语气。

**讲什么**：技能就是 Markdown。提示工程不是玄学，是可版本化、可 diff、可回归测试的工程产物。（技能能导出成 `.md` 文件，可以让学生交作业。）

### 4. 多模型对比（15 分钟）

「收件箱」→ 任一会话 → 底部「比较模型」→ 勾 3 个模型 → 同一段上下文各生成一次 → 并排看，采纳其中一个当草稿。

**讲什么**：同样的提示词，不同模型的差别在哪；延迟和价格怎么权衡；为什么要配后备链（主模型挂了自动降级，而不是整条流水线停摆）。

### 5. 专门演示护栏（20 分钟）

这是这节课最该留下印象的部分。四个演示：

| 演示 | 怎么做 | 看什么 |
|---|---|---|
| **退订** | 在沙盒/手动会话里让对方说「别再给我发了」 | 会话立刻转 `opted_out`，所有未发草稿作废，写进跨账号屏蔽名单；再手动点「重新生成」会被拒绝并给出原因 |
| **硬风险停机** | 让对方说一句涉及自伤的话 | **模型根本没被调用**，会话直接转人工。到「概况 → 事件」里看那条 `handoff` 记录 |
| **软风险降级** | 让对方说「能不能借我点钱，我发你收款码」 | autopilot 也会压成待审核，并标出「涉及资金往来，需要人工确认」 |
| **AI 身份披露** | 把任务改成 autopilot 跑一次 | 第一条自动消息前多出一条独立的身份说明。然后试着把人设的披露文案改成一句不提 AI 的话，再跑——系统会换回内置文案 |

**讲什么**：能力越强，边界越要写在结构里。这几条不是提示词里的一句「请不要……」，是代码路径。让学生去 `src/server/agent/guards.ts` 里找对应的函数，这比讲十遍伦理管用。

### 6. 讨论（5 分钟）

可以抛的问题：

- 我们把「自动加陌生人 + 自动开聊」这个功能删掉了。技术上做得到，为什么不做？
- 如果对方全程不知道在跟 AI 说话，最后成交了，这算不算欺骗？分界线在哪？
- 沙盒里的「目标用户」也是模型，它比真人配合得多。用这个分数去预测真实转化率，错在哪？

## 布置作业的几个方向

1. **写一个技能**：给定一个场景（比如「处理『你们是不是骗子』这类质疑」），写一个 `.md` 技能，在沙盒里跑三种不同人设，提交技能文件 + 三次演练的评分截图 + 一段分析。
2. **找护栏的漏洞**：设计一个对话，让 AI 说出不该说的话（自称真人、发白名单外的链接、复述系统提示）。能触发 `checkOutbound` 的哪个码？触发不了的话，是护栏漏了还是模型自己守住了？
3. **读代码**：`pipeline.send()` 为什么要先把状态标成 `sending` 再发网络请求？如果反过来会出什么事？

---

## 课堂注意事项

- **别在课上连真实社媒账号**。演示用沙盒和手动导入的假对话就够了。
- 截图导入功能演示时，用自己造的截图，不要用真实的私聊记录——哪怕打了码。
- 如果要展示真模型，提前把 key 配好并用 `keychain:` 引用，屏幕上只会显示引用名不显示密钥。
- 「概况」页的花费统计可以顺带讲成本意识：一节课跑几十次生成，真模型大概多少钱，界面上有数。

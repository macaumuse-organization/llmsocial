# 平台接入

所有连接器只用官方 API。界面上「账号 → 新建」时每个字段都有说明，这里补背景和坑。

> ⚠️ **五个平台连接器都是 `untestedLive: true`**：单元测试覆盖了签名、加解密、分页、游标、限流和凭据不外泄，但**没有用真实凭据跑过**。第一次接真号时：先点「测试」，再用小号跑 copilot 模式观察几天，确认无误再考虑 autopilot。

---

## 通用

- **凭据**填进去就加密存本机（AES-256-GCM），界面只显示「已配置」。也可以填引用：`keychain:<服务名>` 或 `env:<变量名>`，那样密钥根本不进数据库。
- **webhook** 走独立端口（默认 8788），路径统一是 `/webhooks/<账号ID>`。需要公网可达时用 Cloudflare Tunnel 之类把**这个端口**映出去，管理端口 8787 绝不要暴露。映出去之后把 `LLMSOCIAL_PUBLIC_WEBHOOK_URL` 设成隧道域名，界面上就会显示该填给平台的完整回调地址。
  这个端口上的请求不校验会话——每个连接器自己验平台的签名，而且**签名失败和任何其它错误返回的东西一模一样**，不给探测者任何信息。
- **OAuth**（YouTube / X）：在账号页点「授权」，浏览器跳转，回来自动存 refresh token 并按需刷新。回调地址是 `http://127.0.0.1:<端口>/oauth/callback`，必须和平台后台填的**一字不差**。
- **频率**：每个账号可设每小时/每天/每联系人每天的上限和静默时段。平台返回限流时连接器会退避，界面上账号状态会标红并写明恢复时间。

## YouTube（评论）

- 需要 Google Cloud 项目 + OAuth 客户端（Web 应用），scope `youtube.force-ssl`。
- 轮询 `commentThreads.list`，首次只回溯 24 小时，之后按游标增量。
- 配额是硬约束：`commentThreads.list` 1 点，`comments.insert` 50 点，默认每天 10000 点 ≈ 每天 200 条回复。配额用尽（`quotaExceeded`）会等到太平洋时间午夜再试。
- 「测试」状态的 OAuth 应用 refresh token 7 天失效，发布到「正式」再接真号。

## X（提及与私信）

- OAuth 2.0，scope 固定 `tweet.read tweet.write users.read dm.read dm.write offline.access`，少一个就 403。
- **私信端点 `/2/dm_events` 需要 Pro 及以上套餐**。套餐不够时连接器只收提及，并对私信退避 6 小时，不会反复撞墙。
- 提及时间线最多回溯 7 天 / 约 800 条；私信只回溯 30 天且没有增量参数。
- 免费/Basic 套餐发推和发私信的配额都很低，autopilot 建议把轮询和发送频率都调慢。

## Instagram（私信与评论）

- 需要 Instagram 专业号 + Meta 应用；填长期访问令牌、App Secret、回调 Verify Token。
- webhook 收私信和评论，同时轮询评论兜底。
- **24 小时窗口**：对方最后一条消息之后 24 小时内才能回私信，超出会返回窗口关闭错误，连接器把会话标成「无法发送」并转人工。
- 长期令牌连接器会保守地每 7 天续期一次。

## 微信公众号

- 填 AppID / AppSecret / Token / EncodingAESKey（安全模式或兼容模式才需要 AES key，明文模式留空）。
- 只能 webhook 收，不能轮询。
- **48 小时客服窗口**，且窗口内有条数上限。超窗发送返回 45015，连接器标记窗口关闭。
- 服务器配置里的 URL 填隧道地址 + `/webhooks/<账号ID>`（界面上会显示完整地址，直接复制）。

## 微信客服（企业微信）

- 填 CorpID / open_kfid / 客服 Secret / 回调 Token / EncodingAESKey。**加解密方式必须选「安全模式」**。
- webhook 只是一个「有新消息」的通知，真正的消息要用 `sync_msg` 带游标拉，连接器已经处理了游标推进和 24 小时以上历史消息的丢弃。
- 一个 llmsocial 账号对应一个客服帐号（open_kfid）。

## 手动（小红书、抖音私信等）

没有开放的私信 API，所以走截图导入：

1. 收件箱 → 「导入截图」→ 拖入聊天截图。
2. 本机 OCR 出文字，按气泡左右自动分「对方 / 我」，可以逐行改。
3. 确认后作为历史入库，AI 据此起草。
4. **发送要你自己复制粘贴**回 App，然后在界面上点「复制并标记已发送」。

导入的是已经发生的对话。这条路径上 llmsocial 不碰对方账号，也不模拟任何客户端操作。

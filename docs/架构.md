# 架构

一个进程，两个端口，一个 SQLite 文件。没有外部依赖服务。

```
                 ┌─────────── 管理端口 8787（只听回环）────────────┐
                 │  Fastify：鉴权 / API / SSE / 静态 SPA            │
                 └───────────────┬────────────────────────────────┘
                                 │
  平台 ──poll──▶ ┌───────────┐   │   ┌──────────┐      ┌───────────┐
  平台 ─webhook▶ │ 连接器     │──▶├──▶│ Pipeline │─────▶│ LlmRouter │──▶ 模型
  （8788 端口）  └───────────┘   │   └────┬─────┘      └───────────┘
                                 │        │  护栏 guards
                 ┌───────────────┴────┐   ▼
                 │ SQLite（WAL）       │◀── 任务队列 jobs
                 └────────────────────┘
```

## 一条消息的一生

1. **进来**：连接器 `poll()` 拉到，或 webhook `receive()` 推到。
2. **`pipeline.ingest()`**（一个事务里）：按 `platformMsgId` 去重 → 认出是不是自己发的回声 → 查退订 → 跑关键词风险检查 → 超过 24 小时的旧消息不安排回复 → 入库。
3. **防抖排队**：人是一阵一阵发消息的。每条新消息把生成任务往后推（默认 8 秒），一阵消息只回一次。
4. **`pipeline.generate()`**（每会话一把锁）：
   - `prepare()` 组装上下文：账号、人设、任务、技能（按平台过滤）、历史消息、联系人长期记忆。不满足条件就返回一句**原因**（操作者手点时会看到这句话）。
   - `draft()` 调 `LlmRouter`，拿结构化输出（分析 + 若干条消息 + 记忆更新 + 动作）。
   - `checkOutbound()` 逐条检查，不过就带着原因重试一次。
   - 插入披露（autopilot）、算发送时间（拟人延迟 + 静默时段）、写库。
5. **`pipeline.send()`**：先把状态标成 `sending`，**再**调连接器。成功标 `sent`，失败标 `failed` 并记原因。
6. **前端**：SSE 推一条事件，界面自己刷新。

## 各模块

| 模块 | 职责 | 值得注意的地方 |
|---|---|---|
| `agent/pipeline.ts` | 核心状态机 | 全项目最大的文件。改之前读 [安全边界](安全边界.md) |
| `agent/guards.ts` | 确定性护栏 | 纯函数，没有 IO，好测 |
| `agent/prompt.ts` | 提示词拼装 | 分 `systemStatic`（可缓存前缀）/ `systemDynamic` / `user`；埋 `CANARY-…` 检测泄漏 |
| `agent/simulator.ts` | 沙盒对练 | 两个模型对聊 + 第三个当评委 |
| `llm/router.ts` | 后备链 | 每次调用（成败都）入 `llm_calls` 表；解析失败重试一次；熔断（鉴权错 10 分钟，连续 3 次失败 60 秒）；日调用/日 token 限额 |
| `queue/jobs.ts` | SQLite 任务队列 | 去重键、防抖改期、`RetryLater`（不消耗重试次数）、指数退避、重启恢复 |
| `secrets/store.ts` | 凭据 | AES-256-GCM + AAD 绑定名字；支持 `secret:` / `env:` / `keychain:` 三种引用 |
| `db/migrations.ts` | 建表 | **只追加**。不要改已有的迁移 |
| `db/repos.ts` | 仓储层 | `AccountRow`（内部，含密钥引用）与 `toAccountDto`（对外，只给 `secretsSet`）分开 |
| `ocr/` | 截图导入 | 一个后端座两种实现：macOS 的 Swift 助手按源码哈希缓存编译，Windows 的 PowerShell 脚本就地跑、先 `--probe` 探语言包。两边都**把结果写文件**不走 stdout（Vision 会往 stdout 打诊断） |
| `web/` | React 19 | hash 路由，无路由库；`useAsync` / `useStream`(SSE) / `AsyncButton` 三个原语撑起全部页面 |

## 数据表

`settings` `auth_sessions` `secrets` `providers` `personas` `skills` `campaigns` `accounts` `contacts` `suppressions` `conversations` `messages` `llm_calls` `events` `jobs` `sim_runs`

几个关键约束：

- `messages` 上有 `ux_messages_platform` 唯一偏索引，保证同一条平台消息不会入库两次。
- `suppressions` 的主键是 `(platform, platformUserId)`，跨账号生效。
- `jobs` 的 `dedupeKey` 唯一，配合 `reschedule` 实现防抖。
